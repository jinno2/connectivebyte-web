# ConnectiveByte

自分の関心から記事・診断・ニュースレターへ進む公開サイトです。本人の自己選択を助け、能力や属性を断定しません。

## ローカルで確認する

Node.js 20以上。npmパッケージの追加インストールは不要です。

```sh
npm test
npm run serve
```

公開PDFの検査には Poppler (`pdftotext` / `pdfinfo`) と qpdf が必要です。Ubuntuでは `sudo apt-get install poppler-utils qpdf` で導入できます。未導入・読取り失敗・未対応のPDF内容は検査失敗として停止します。画像・文字対応表のない複合フォント・線形化・増分更新などのPDFは対象外です。検査は本文・構造の文字列・メタデータへの事故的な混入を対象にし、図形として描かれた文字やページ外の描画の意味までは判定しません。公開前の内容確認も必要です。

`http://127.0.0.1:4173`で画面を確認します。
変更した導線、同意、フォーム、狭い画面、リンク先まで確認します。

## 公開対象

配信物は[deploy workflow](.github/workflows/deploy_pages.yml)の`Prepare publish tree`が
作る`_site/`です。リポジトリ全体をサイトのドキュメントルートとして配信しません。
ただしGitリポジトリ自体は公開のため、READMEやテストを含めコミット内容は公開されます。
既存の記事・資料にも[公開規約](AGENTS.md)が適用されます。
制作・編集レビューの通過だけで、個別資料の公開確認を済ませたことにしません。

## プライバシー

職業・年収・能力・性格・外部履歴を推定しません。匿名イベントとメールアドレスを分離し、
同意と明示操作の条件を満たして処理します。現行仕様は`logic.js`・`app.js`と対応テストを参照します。
ローカルサーバーの合格を本番の登録・配信成功とは扱いません。

## 文書と構成

- [長期計画](ORDER.md)、[不変条件](SYSTEM_CONSTITUTION.md)、[発火・停止・公開](AUTOMATION.md)、[作業規約](AGENTS.md)
- `index.html` / `styles.css`: 画面と表示
- `logic.js` / `app.js` / `share.js`: 判定・同意・操作・共有
- `server.js`: ローカル検証用サーバー
- `content/`: 公開記事・資料
- `test/`: 公開ガードと動作検証

入力・導線・公開対象を変更したら、対応する仕様・テスト・計画を同じ変更で更新します。
