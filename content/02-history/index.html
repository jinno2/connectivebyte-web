# 床と天井の価格史 2023-2026

## この記事について

月次トラッカーは 2026-08 の基準値から前向きに観測する。本記事はその前段として、
GPT-4 が公開された 2023-03 から 2026-08 までの価格系列を埋め戻す。
系列は2本。床（日常タスクの品質を満たす最安帯）と天井（その時点の旗艦）。
数値は API 公表単価（短文脈・per 1M tokens）で、検証済みの出典を根拠資料に残す。

## 天井系列（旗艦）

| 公開 | モデル | input / output（per 1M） |
|---|---|---|
| 2023-03 | GPT-4（8K） | $30 / $60 |
| 2023-11 | GPT-4 Turbo | $10 / $30 |
| 2024-05 | GPT-4o | $5 / $15 |
| 2024-08 | GPT-4o（2024-08-06版） | $2.50 / $10 |
| 2024-12 | o1 | $15 / $60 |
| 2025-08 | GPT-5 | $1.25 / $10 |
| 2026-07 | GPT-5.6 Sol | $4 / $20 |

## 床系列（最安帯）

| 公開 | モデル | input / output（per 1M） |
|---|---|---|
| 2023-03 | GPT-3.5 Turbo | $2 / $2（代表タスク換算 $0.0025/回） |
| 2024-05 | Gemini 1.5 Flash | 代表タスク換算 $0.000225/回 |
| 2024-07 | GPT-4o mini | $0.15 / $0.60 |
| 2025-02 | Gemini 2.0 Flash | 床の水準を維持 |
| 2025-08 | GPT-5 nano | $0.05 / $0.40（参考） |
| 2026-07 | GPT-5.6 Luna | $0.20 / $1.20 |

参考として GPT-5 nano は単価では最安だが、床の定義（日常タスクの品質を満たす
最安帯）では GPT-5.6 Luna を床とする。系列の比較は同一定義の枠内で行う。

## 読み方

床は3年半で約1000分の1に下がった（2022-11〜2026-05・32バージョンの追跡データ）。
GPT-3.5 Turbo が $0.0025/回で最初の床を作り、Gemini 1.5 Flash が10分の1強に
引き下げ、以降も下がり続けている。誰も努力しなくても床は上がる。市場側の力である。

天井の単価は同じ期間、input が $1.25〜$30・output が $10〜$60 の帯のなかで動いた
（桁は1つも下がっていない）。GPT-4 から GPT-4o では input が12分の1まで下がったが、
推論性能を旗艦に載せた o1 は $15 に、GPT-5.6 Sol は $4 に再び上に置かれている。
性能の最上位が作り直されるたび、その時点の最高性能には価格が付き直す。

つまり価格の面でも系列は非対称である。床は自動で上がる。天井は、触れた人の
支払いと接触の履歴のなかでしか動かない。単価の低下と性能の向上は別の系列で、
性能あたりの価格を比較するには性能の実測が要る。それが月次トラッカーの
代表タスク（凍結した入力・1〜5採点）で前向きに蓄積する系列である。

## 出典

価格は各社の公表単価（短文脈）。検証日と URL は根拠資料（evidence.yaml の
ev-price-history-ceiling・ev-price-history-floor・ev-price-decline-history・
ev-price-2026-08）に残している。為替は150円/$。
